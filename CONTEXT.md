# Context: PromptApp

## What this product is

A Shopify app that lets merchants describe storefront UI features in plain English. Instead of installing another app, a merchant types a prompt and receives a live, draggable theme block — generated by AI, deployed to a CDN, and rendered in a sandboxed iframe.

## Domain glossary

**Feature** — a single AI-generated storefront UI widget (e.g. countdown timer, stock badge, announcement bar). A feature has a lifecycle: `draft → published → enabled/disabled/error`.

**Feature slot** — one active feature running on a store. Plans are gated by slot count, not by the number of features ever generated.

**Generation** — one invocation of the AI pipeline (prompt → spec → HTML/CSS/JS). Counts against the store's monthly generation credits.

**Generation credit** — a unit of AI usage. Each generation consumes one credit. Credits reset each billing cycle. Rate-limited to 5/hour per store regardless of plan.

**Spec** — an internal JSON document produced silently by the generation pipeline before code is written. Stored in the database; never shown to merchants. Used for debugging and future re-generation.

**Feature Runtime** — the sandboxed `<iframe>` shell served from Cloudflare R2. All generated code runs inside it. Has no access to the merchant's DOM, cookies, or Shopify APIs beyond what is passed via postMessage.

**App Embed Block** — a Shopify theme extension that installs once across the storefront. On every page load it reads storefront context and broadcasts it to all active Feature Runtime iframes via postMessage.

**Generic App Block** — a single Shopify theme App Block registered once and reused for every feature. The merchant selects which feature to display via a block setting (feature ID). Draggable in the theme editor.

**PostMessage contract** — the typed data payload (`PostMessagePayload`) sent by the App Embed Block to every Feature Runtime iframe on page load. Contains: `{ shop, pageType, product, cart, customer }`. Defined in `packages/shared`.

**Plan** — the merchant's subscription tier. Three tiers: Free (3 slots, 15 credits/month), Pro ($29/month, 10 slots, 100 credits/month), Business ($99/month, unlimited).

**Auto-disable** — automatic feature deactivation triggered when a feature's error count exceeds 5 errors in a 10-minute window. Sets feature status to `error` and notifies the merchant.

**CDN URL** — the public URL of a feature's compiled static file on Cloudflare R2. The iframe `src` points directly to this URL. No server involvement on shopper page loads.

## Key architectural decisions

- All generated code runs in a sandboxed iframe — never injected directly into the storefront DOM.
- Generated features are pre-built into static files and uploaded to Cloudflare R2 on publish. Zero server latency per shopper page load.
- The postMessage contract is the only data channel between the storefront and a Feature Runtime.
- One generic App Block covers all features — Shopify blocks are statically defined at deploy time, so dynamic registration is not possible.
- Claude Haiku 4.5 is the default generation model. Claude Sonnet 4.6 is used as a fallback on merchant retry.
- The internal spec is never exposed to merchants. It exists for debugging and model-upgrade re-generation.

## Package map

| Package | Role |
|---|---|
| `apps/web` | Remix app — OAuth, dashboard, generation pipeline, billing |
| `extensions/theme` | Shopify CLI theme extension — App Embed Block + Generic App Block |
| `packages/feature-runtime` | Iframe shell — postMessage listener, error beacon |
| `packages/shared` | Shared TypeScript types — PostMessage contract |
